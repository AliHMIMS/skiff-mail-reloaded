# skiff-front-graphql

`skiff-front-graphql` is an open-source TypeScript library containing React hooks and utility functions for a global GraphQL API shared between the Skiff's applications and servers. This package powers web, mobile, and server applications inside Skiff's end-to-end encrypted, privacy-first product suite, including Mail, Pages, Drive, and Calendar applications.
